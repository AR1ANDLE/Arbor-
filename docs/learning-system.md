# Learning system

The current academy view introduces a short path covering Git's three working areas, the first commit, and branches. The command guide filters the actions available in the playground and can prefill supported commands.

Each successful command displays a short explanation and a live summary of the working tree, index, recent repository history, and HEAD. The app does not yet persist lesson progress or challenge results and does not claim completion for lessons a learner has not finished.

The playground is a free-form practice space. Resetting it requires confirmation and removes its temporary files and repository history.
