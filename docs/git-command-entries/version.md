# `git version`
- **Category:** Setup & configuration
- **Git help group:** Ancillary Commands / Interrogators
- **Difficulty:** intermediate
- **Typical risk:** informational
- **Deprecated:** no
- **Experimental:** no
- **Playground:** documentation only
- **Target version:** 2.56.0.windows.1
## Overview
Display version information about Git
## Syntax
```text
git version [--build-options]
```
## Full options, examples, output, effects, and recovery
The version-matched manual is the authoritative reference for every option and its exact behavior: [/git-docs/git-version.html](../../public/git-docs/git-version.html) · [Official Git 2.56.0 manual](https://git-scm.com/docs/git-version/2.56.0.html).

With no options given, the version of git is printed on the standard output.

Note that git --version is identical to git version because the
former is internally converted into the latter.
