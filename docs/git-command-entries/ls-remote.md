# `git ls-remote`
- **Category:** Sharing & updating
- **Git help group:** Low-level Commands / Interrogators
- **Difficulty:** advanced
- **Typical risk:** safe
- **Deprecated:** no
- **Experimental:** no
- **Playground:** documentation only
- **Target version:** 2.56.0.windows.1
## Overview
List references in a remote repository
## Syntax
```text
git ls-remote [--branches] [--tags] [--refs] [--upload-pack=]
[-q | --quiet] [--exit-code] [--get-url] [--sort=]
[--symref] [ […​]]
```
## Full options, examples, output, effects, and recovery
The version-matched manual is the authoritative reference for every option and its exact behavior: [/git-docs/git-ls-remote.html](../../public/git-docs/git-ls-remote.html) · [Official Git 2.56.0 manual](https://git-scm.com/docs/git-ls-remote/2.56.0.html).

Displays references available in a remote repository along with the associated
commit IDs.
