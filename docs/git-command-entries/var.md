# `git var`
- **Category:** Plumbing & object storage
- **Git help group:** Low-level Commands / Interrogators
- **Difficulty:** advanced
- **Typical risk:** informational
- **Deprecated:** no
- **Experimental:** no
- **Playground:** documentation only
- **Target version:** 2.56.0.windows.1
## Overview
Show a Git logical variable
## Syntax
```text
git var (-l | )
```
## Full options, examples, output, effects, and recovery
The version-matched manual is the authoritative reference for every option and its exact behavior: [/git-docs/git-var.html](../../public/git-docs/git-var.html) · [Official Git 2.56.0 manual](https://git-scm.com/docs/git-var/2.56.0.html).

Prints a Git logical variable. Exits with code 1 if the variable has
no value.
