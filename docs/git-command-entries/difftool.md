## Overview
Show changes using common diff tools
## Syntax
```text
git difftool [] [ []] [--] […​]
```
## Full options, examples, output, effects, and recovery
The version-matched manual is the authoritative reference for every option and its exact behavior: [/git-docs/git-difftool.html](../../public/git-docs/git-difftool.html) · [Official Git 2.56.0 manual](https://git-scm.com/docs/git-difftool/2.56.0.html).

git difftool is a Git command that allows you to compare and edit files
between revisions using common diff tools. git difftool is a frontend
to git diff and accepts the same options and arguments. See
git-diff(1).
