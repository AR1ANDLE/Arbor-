- **Category:** Specialized & interoperability

## Overview
Graphical alternative to git-commit
## Syntax
```text
git citool
```
## Full options, examples, output, effects, and recovery
The version-matched manual is the authoritative reference for every option and its exact behavior: [/git-docs/git-citool.html](../../public/git-docs/git-citool.html) · [Official Git 2.56.0 manual](https://git-scm.com/docs/git-citool/2.56.0.html).

A Tcl/Tk based graphical interface to review modified files, stage
them into the index, enter a commit message and record the new
commit onto the current branch.  This interface is an alternative
to the less interactive git commit program.

git citool is actually a standard alias for git gui citool.
See git-gui(1) for more details.
